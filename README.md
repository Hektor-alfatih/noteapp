📝 My Notes App

Aplikasi sederhana Note App yang dibuat menggunakan Flutter.
Di aplikasi ini pengguna dapat membuat catatan, menghapus catatan, serta mengganti tampilan antara Dark Mode dan Light Mode.

✨ Fitur
➕ Menambahkan catatan
🗑️ Menghapus catatan
🌙 Dark Mode
☀️ Light Mode
📱 Tampilan sederhana dan mudah digunakan
📸 Preview

🛠️ Teknologi yang Digunakan
Flutter
Dart
📂 Struktur Fitur
Home Page
Add Note
Delete Note
Theme Switcher (Dark & Light Mode)
